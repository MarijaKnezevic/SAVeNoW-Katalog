# SAVeNoW-Katalog and Twin4Clim Katalog
Repository for images included in the SAVeNoW Katalog and Twin4Clim Katalog

## Description
In this repository are included images for some of the catalog entries for the SAVeNoW-Katalog (https://catalog.savenow.de/) and Twin4Clim Katalog (https://twin4clim.gis.lrg.tum.de/). The images are mostly used for description of the catalog entries.
